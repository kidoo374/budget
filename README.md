# Personal Budget & Expense Tracker

A simple Personal Budget & Expense Tracker built with **HTML and CSS** as part of my Week 2 web development project.

## Project Description

This project is the foundation of a fully working Budget Tracker that will be developed throughout the coming weeks.

The current version focuses on:

* HTML page structure
* CSS styling
* Expense forms
* Expense tables
* Multimedia content
* Interactive HTML elements
* Advanced CSS selectors

## Features

### Add Expense Form

The form includes:

* Expense Name
* Amount
* Category
* Add Expense button

Available categories:

* Food
* Transport
* Rent
* Entertainment
* Other

### Expense Table

The tracker currently contains sample expenses with:

* Name
* Amount
* Category
* Date

The table also includes alternating row colors and a hover effect.

### Multimedia

The page includes:

* A budget tracker icon
* An embedded YouTube video

### Interactive Elements

The project uses:

* `<details>` and `<summary>` for a collapsible help section
* Table row hover effects
* Input focus effects
* Button hover effects
